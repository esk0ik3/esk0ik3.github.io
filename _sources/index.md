# ベクトルビームについて

ベクトルビームとは，スカラービームとは異なり，ビーム断⾯内で偏光状態が空間的な分布を持つ光を指す(Fig. 1.1)．代表例として，Fig. 1.2 に⽰すような電場の振動⽅向が中⼼から放射状に分布するラジアル偏光ビームや，同⼼円状に分布するアジマス偏光ビームがあり，これらはスカラービームとは異なる集光特性を持つ[1]．ラジアル偏光ビームは⾼い NA を持つレンズで集光すると，中⼼に強⼒な縦電場成分を⽣成し，回折限界を超えた微⼩スポットを形成できるため，光トラッピングに応⽤されている[2-4]．また，壁⾯に対して常に p 偏光成分を持つため，吸収率が⾼く，⽳あけ加⼯や切断加⼯における加⼯効率やアスペクト⽐の向上が可能である[5]．⼀⽅，アジマス偏光ビームは，中⼼強度がゼロとなるドーナツ状の形状を維持する特性を持つため，STED 顕微鏡[6]や光メモリ[7]に応⽤されている．また，壁⾯に対して常に s 偏光成分を持つため，反射率が⾼く，⽳の奥まで光が届くことから，深い⽳を掘ることが可能である[8]．これらの応⽤については，所望の光強度分布および偏光分布を⾼精度に制御したベクトルビームの⽣成が重要である．
